# shiphead

Ship structured JSON head payloads without a heavyweight toolkit.

**Site:** https://theworker02.github.io/shiphead/

## Install / run

```bash
git clone https://github.com/theworker02/shiphead.git
cd shiphead
node src/cli.js
node --test
```
